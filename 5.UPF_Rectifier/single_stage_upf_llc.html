5.UPF_Rectifier · single-stage study

One half bridge, two jobs: the Dornbirn rectifier and an LLC on the same switches

This is the single-stage idea of the PCIM 2024 paper by Ramezan Ghanbari et al., built on the Dornbirn rectifier's equations from the ECCE 2024 paper. The half bridge S1–S2 drives winding L2 of the coupled inductor, which makes the input resistive, and at the same time drives a half-bridge LLC tank that delivers 48 V at up to 60 W. Two switches and one controller replace a PFC stage plus a DC/DC stage. The price is that there is only one control knob, the switching frequency. It is used to hold 48 V, so the bus voltage is no longer controlled directly. It settles wherever the two stages balance, and that point moves with load.

1. Three equations, one knob

(a) Input power, from the Dornbirn rectifier. In IRCM the input is a resistor whose value is set by the switching frequency (ECCE paper, eqs. 14 and 20). The bus voltage does not appear:

R_in = 8·fs·√(L1·L2)·(1 − k²)/k P_in = V_m² / (2·R_in) ∝ 1/fs

(b) Output, from the half-bridge LLC. The same switch node drives the tank with a square wave of ±VC = ±Vbus/2 around the midpoint. With first-harmonic approximation (FHA), normalized frequency fn = fs/fr, inductance ratio Ln = Lm/Lr and quality factor Q:

V_C · M(fn, Q) = N · V_o , M(fn, Q) = 1 / √( [1 + (1 − 1/fn²)/Ln]² + Q²·(fn − 1/fn)² ) Q = Z0 / R_ac , R_ac = 8·N²·R_o / π² , R_o = V_o² / P_o → Q = Q0 · P_o / P_o,full

(c) Power balance on the bus. In steady state the rectifier delivers what the LLC draws: η·P_in = P_o.

The controller turns the only knob, fs, to hold 48 V. Combining (a) and (c) fixes fs from the power alone. Then (b) has only one unknown left, VC. So the bus voltage is an outcome, not a set point:

fs(P_o) = fs,full · P_o,full / P_o (from a + c, IRCM) V_bus(P_o) = 2·N·V_o / M( fs(P_o)/fr , Q0·P_o/P_o,full ) (from b)

With x = Po/Po,full and the full-load design point at fn0 = fs,full/fr, the two load-dependent terms combine neatly. Q·fn = Q0·fn0 stays constant and Q/fn = Q0·x²/fn0, which gives a closed form for the bus voltage against load:

V_bus(x) = 2·N·V_o · √( [1 + (1 − x²/fn0²)/Ln]² + Q0²·(fn0 − x²/fn0)² ) light-load limit (x → 0): V_bus,max = 2·N·V_o · √( (1 + 1/Ln)² + (Q0·fn0)² )

Reading it: at full load (x = 1) the square root equals 1/M(fn0, Q0), so Vbus is the design value. As the load falls, fs rises, the LLC moves above resonance where its gain is below 1, and the bus has to rise to keep 48 V. It does not rise without limit: it approaches Vbus,max, set only by Ln, Q0 and fn0. This is the paper's statement that the bus is "limited to the reflected secondary voltage". Larger Ln and smaller Q0 keep it lower.

Why the bus finds this point by itself. Suppose the bus is a little too high. To hold 48 V the LLC needs less gain, so the controller raises fs. By (a) a higher fs means less input power, so the bus discharges back down. A low bus is corrected the same way. So no separate bus loop is needed: the output loop plus the Dornbirn power law form a stable negative feedback on the bus. The load-step simulation below shows it.

2. The rectifier conditions, now with a moving bus

The ECCE paper's conditions use VC = Vbus/2. They still hold, but VC is no longer fixed. Since the bus rises at light load, the conditions are hardest to meet at full load:

no CCM (eq. 17): V_bus ≥ V_m IRCM, unity PF (eq. 18): V_bus ≥ 2·V_m/(nk − 2) no zero-crossing (eq. 19): nk > 2 THD (closed form): THD² = π·S₂/(4·S₁²) − 1 , S₁, S₂ from nk and ρ = V_C/V_m

If IRCM is lost (low nk), the input power depends a little on ρ as well: P_in = (V_m²/2R_in)·(4/π)·S₁(ρ). The page then solves (a) to (c) numerically instead of with the closed form. The two agree exactly while IRCM holds.

3. Light load: fs limit and burst mode

fs ∝ 1/Po, so it grows quickly at light load. At a maximum frequency fs,max the lowest continuous power is

P_o,min = P_o,full · fs,full / fs,max

Below that, the converter runs in bursts at fs,max and stops in between, with the output capacitor holding 48 V. In each burst the LLC has to deliver the same power it did at Po,min, and the rectifier delivers Pin(fs,max). So the bus stays at Vbus(Po,min) and simply stops rising. The burst on-fraction is D = Po/Po,min, and the power factor drops to √D, because the current is a clean sine while running and zero while stopped.

4. The 100 Hz ripple problem of a single stage

The input power pulses at 100 Hz. The only energy buffer is the bus, so it carries a ripple

ΔV_bus,pp ≈ P_in / (ω·C_bus·V_bus) , C_bus = Cb/2 (Cb1, Cb2 in series) PCIM paper eq. 20, sizing: Cb = P_o / (π·f_line·V_bus·ΔV_bus)

Because one knob serves both stages, the ripple forces a choice:

  • Fast output loop: fs follows the bus ripple to keep 48 V flat. But Rin ∝ fs, so the input resistance is now modulated at 100 Hz and the input current is no longer a pure sine. THD rises with the ripple.
  • Slow output loop: fs is held constant over each mains cycle, so Rin is constant and the input current stays sinusoidal. The LLC gain is then fixed within the cycle, so the output carries the bus ripple in proportion: ΔV_o/V_o ≈ ΔV_bus/V_bus.

A larger Cbus reduces both effects. The simulation lets you compare the two loops.

5. Soft switching: the two currents add

At the S2 → S1 edge, the current flowing into the switch node charges it toward the + rail and gives S1 zero-voltage turn-on. Two currents contribute:

i_into_sw(t0) = i₂(t0) − i_r(t0) = I_g2 + |I_r|·sin φ I_g2 : Dornbirn L2 current at t0, from the interval model with zero local average of i₂ (ECCE paper, section III-D) I_r, φ: LLC tank current and impedance angle by FHA, I_r = (4/π)·V_C / |Z_in|

Both are positive in normal operation: Ig2 because i2 has zero average and peaks at t0, and the LLC term because the tank is inductive above resonance. The half-period later, S1 → S2 is the mirror image. So sharing the switches helps ZVS: the PFC current alone is usually larger than the LLC magnetizing current. The cost is RMS current in the switches, which carry both.

7. Assumptions and how this differs from the paper

  • 230 Vrms, 50 Hz. Output 48 V, 60 W. Overall efficiency a constant 90% (the paper measured about 87–88% at full load). Coupled-inductor coupling k = 0.9. Full-load switching frequency 100 kHz.
  • The rectifier uses the Dornbirn two-winding coupled inductor and its equations. The PCIM prototype uses a variant (a buffer inductor Lf plus windings LC2 and LC3 in both lines, with Iavg = nC·T·Vin/(4Lf), its eq. 14), which is also resistive and also ∝ 1/fs, so the bus behaviour is the same in kind.
  • The LLC turns ratio N is chosen so that the bus is Vbus,full at full load. The LLC gain uses FHA, which is only approximate well above resonance. That is one reason the paper's measured light-load bus (432 V) sits below the FHA limit with its own Ln and Q.
  • The fast output loop is ideal, adjusting fs instantly. The slow loop updates fs once per mains half cycle. Burst mode is treated on average. Switching ripple and dead time are not shown.
