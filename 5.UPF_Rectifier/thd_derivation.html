Companion to “A Rectifier with Inherent Unity Power Factor”, ECCE 2024

Deriving a closed-form THD for the UPF rectifier

The paper gives exact equations for one switching period and proves the input is resistive in IRCM. It stops there for THD and reports numbers. This page goes from those equations to a closed-form THD in seven steps, with a figure for each step. Move the sliders and every figure and number updates.

THD = 3.28%

The plan

  1. Write the slope of the input current i1 in each of the paper's four intervals.
  2. Find the input voltage at which the reverse current (IRCM) disappears.
  3. Below that voltage: use the paper's result, the input is a pure resistor.
  4. Above it (DCM): average the triangular i1 pulse over one switching period to get a new formula.
  5. Put both pieces together as the input current over a mains period, i(θ).
  6. Write THD with Fourier analysis, using the symmetry of i(θ).
  7. Solve the integrals in closed form, then check against brute-force numerics.

Throughout, voltages are divided by the mains peak Vm and currents by Vm/Rin. So s = vin/Vm = sin θ, ρ = VC/Vm, and the ideal current is simply i = s.

1Slopes of i1 in each interval

The paper's equation (3) gives the current slopes from the two winding voltages: di/dt = Γ·V, with Γ the inverse of the inductance matrix. For i1 only the first row matters:

di1dt=Γ11V1+Γ12V2,Γ11=L2L1L2−M2,Γ12Γ11=−ML2=−nk
This is where nk enters. With V1 = vin − Vx, Vx = ±2VC (set by which diode pair conducts) and V2 = ∓VC (set by S1 or S2), each interval has a constant slope:

2Where the reverse current dies

At the end of interval 3, i1 reaches zero. For it to continue into negative values, the diodes D2 D3 must take over, and then the slope is a₄. A negative current can only grow if a₄ is negative. If a₄ ≥ 0, no diode pair can carry current and i1 stays at zero: that is DCM.

a4<0⟺vin<(nk−2)VC⟺s<a≡(nk−2)ρ
This is the paper's condition (18). The number a is the knee of the whole story: it is the normalized input voltage where IRCM ends.

3Below the knee: a pure resistor

With all four intervals present, the paper solves the four unknowns tα, tβ, Iα, Iβ and averages i1 (its eqs. 8–13). Everything cancels except one term:

Iin=−Γ12T8vin=vinRin⇒i=sfors≤a
In normalized units the IRCM current is exactly the sine. No distortion comes from this region.

4Above the knee: averaging the DCM pulse

In DCM there is no reverse current, so i1 starts each period at zero. It rises with slope a₂ for the whole first half period, then falls with slope a₃ until it hits zero again (Figure 1, right). The pulse is two triangles:

Iα=a2T2,tα=−Iαa3,Iin=1T·Iα2(T2+tα)=T8·a2(a3−a2)a3
Now substitute the slopes. a₃ − a₂ = −2nk·Γ₁₁VC, and nk·Γ₁₁·T = −Γ₁₂·T = 8/Rin. The inductances disappear and only nk and VC remain:
Iin=2VCRin·vin+(nk−2)VC(nk+2)VC−vin⇒i=cs+ab−s
with a = (nk−2)ρ, b = (nk+2)ρ, c = 2ρ. Check: at s = a this gives c·2a/(b−a) = 2ρ·2a/(4ρ) = a, so it joins the resistor line without a jump.

6THD from Fourier analysis

i(θ) is odd, and symmetric about π/2. Those symmetries mean it contains only odd sine harmonics, all in phase with the voltage, and every integral can be taken over a quarter period. Two numbers are needed: the fundamental amplitude and the RMS value.

The brute-force column simulates 20,000 switching periods over one mains cycle with the full interval equations and takes the Fourier transform. It agrees with the closed form to every printed digit, which confirms the algebra. The formula is exact for the ideal model: ideal diodes and switches, no dead time, constant VC, fs ≫ fL, and each DCM period starting from zero current. For the prototype the paper reports 2.6%. That difference comes from the DCM step: the paper keeps its IRCM expression for Iα in DCM, while step 4 here starts each DCM period from zero. A real circuit will differ from both because of losses, dead time and bulk-voltage ripple.
